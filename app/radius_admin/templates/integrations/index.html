Available integrations

Remote RADIUS MFA server
Any RADIUS server that checks the password and asks for the second factor itself, for example a Network Policy Server with the Microsoft Entra multifactor extension, privacyIDEA or an Okta RADIUS agent. Serves directory accounts; FreeRADIUS still checks the device admin group.{% if not remote_allowed %} Not available in FIPS mode.{% endif %}
Duo Authentication Proxy
Installed on this server; checks local and directory accounts here, then sends a Duo push, phone call or passcode prompt. Planned: installing and setting it up from this page.
Planned
Okta RADIUS agent on this server, built-in authenticator codes (TOTP), privacyIDEA on this server.

The device must wait long enough for the person to answer: set its RADIUS timeout to about 60 seconds for logins that need a second factor. 802.1X network access never uses a second factor.
