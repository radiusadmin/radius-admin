Access rules

For 802.1X (EAP-TLS) devices, the first rule whose AD group matches assigns the VLAN. Wired rules match Ethernet ports; wireless rules match the SSID. No match means reject. FreeRADIUS reads these rules on every authentication, so saved changes apply to the next one.
